# Developing with Streamlit

Use the Streamlit documentation bundled with the project's
Python virtual environment.

Skill references:
`.venv/Lib/site-packages/streamlit/.agents/skills/developing-with-streamlit/references/`

Before implementing changes:
1. Read the relevant reference documentation for the task.
2. Follow Streamlit best practices.
3. Prefer native Streamlit APIs.
4. Use `streamlit docs st.<command>` to verify API details.
